# 🌤️ Medellín Weather & News

A beautiful, modern weather app showing real-time weather and local news for Medellín, Colombia.

![Made with ☢️ by VaultGhost](https://img.shields.io/badge/Made%20with-☢️%20VaultGhost-yellow)

## Features

- **Real-time Weather**: Current temperature, humidity, wind speed, and conditions
- **5-Day Forecast**: Plan your week ahead
- **Local News**: Latest news from Colombian sources
- **Responsive Design**: Looks great on mobile and desktop
- **Auto-refresh**: Updates every 10 minutes

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks!)
- [Open-Meteo API](https://open-meteo.com/) for weather data (free, no API key needed)
- Colombian news RSS feeds

## Local Development

Just open `index.html` in your browser, or serve it:

```bash
# Using Python
python -m http.server 8000

# Using Node
npx serve
```
